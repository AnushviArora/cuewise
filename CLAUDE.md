# Cuewise

Cuewise gives accurate lecture captions grounded in uploaded lecture slides/notes, plus an "Ask this lecture" chatbot.

## Stack
- Next.js + TypeScript, local git.

## Rules
- The OpenAI API key lives only in `.env.local` (gitignored). Never log it, print it, or hardcode it.
- No FOX code, branding, data, or screenshots anywhere in the project.
- Lecture videos come from MIT OpenCourseWare only, credited under CC BY-NC-SA. No YouTube downloads.
- Code comments should be short and in plain language.
- Only change files related to the feature being worked on. Ask before restructuring anything else.
